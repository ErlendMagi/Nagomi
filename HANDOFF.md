# Nagomi — session handoff (written 2026-07-19, for working from Claude Web / any device)

Nagomi is a passive-listening Japanese SRS app (React Native / Expo 56, Android). Sole tester: Erlend, on a Bigme HiBreak Pro e-ink phone (Android 14) — but the design targets COLOR phones; e-ink is a constraint, not the aesthetic. This file is the context a fresh Claude session needs. Treat it like the project's memory.

## Standing rules (user-set, non-negotiable)
- **Money gate**: never start anything that costs money without explicit consent. Art generation has a HARD $50 cap enforced in code (`data/art_ledger.json`, charge-before-request); ~$29.9 booked, ~$25 actually billed.

## Art pipeline (all in `scripts/art_pipeline/`)
- `generate_art.mjs bases|variants|backgrounds|ledger` — Gemini image API (`lib/gemini_image.mjs`, key in `.env` as GEMINI_API_KEY — NOT in git). Ledger-capped at $50, charges only pending items, skips existing files (re-run = retry failures for free).
- **Style is LOCKED via image anchor**: every base is conditioned on `art_raw/style_ref.png` (the approved Sakura). NEVER restyle by stacking prompt clauses — that caused two rejected style drifts. To tune style, change the anchor image.
- `crop_bases.mjs` (multi-view sheets → single figures), `build_assets.mjs` (trim → flood-fill cutout via `lib/cutout.mjs` → WebP + index), `variant_sheets.mjs` (review contact sheets).
- Raw renders in `art_raw/` (NOT in git — lives on the home PC only). Regenerable from the bible + anchor if needed.
- `data/art_bible.json` = single source of truth for characters (visual/palette/prop/reactions/variantNote) and scene prompts. Cheap to edit, expensive to re-render — always re-render only affected items.

## Key invariants (hard-won — do not regress)
- Playback ENGINE-TRUTH: all queue lookups via `engine.progress().step` / `engine.current()`; `stepIndexRef` is a uniqueness token ONLY (resume-rewind desync caused audio-order bugs).
- Bigme: never `File.downloadFileAsync` (hangs); fetch→arrayBuffer→File.write with manual AbortController; always `blob.close()`; never stat files in loops on external storage.
- expo-sqlite: services-owned private `useNewConnection` handles only (pooled throwaway handles caused process-wide NPE brick).
- Any review-picker change → regenerate `data/prediction_table.json`.
- The 6 locked favorite characters (never touch): Sakura (style anchor), Goro, Yuki, Mei, Tatsuya, Dr. Saito.

## Build & deliver
- Local: `cd android && ./gradlew assembleRelease` (JDK 17), copy APK to `dist/nagomi.apk`, LAN server (scheduled task NagomiDevServer, :8765) serves it — Bigme downloads from `http://10.0.0.32:8765/nagomi.apk`.
- Cloud (travel): GitHub Actions workflow `.github/workflows/build-apk.yml` builds on every push and attaches `nagomi.apk` to the rolling `latest` release — install from the GitHub releases page on any phone.
- `npm install` needs `--legacy-peer-deps`.
